# 1. 練習了哪些當週上課的主題:

這週上課的重點是 JavaScript 基礎與網頁互動，我們在原本的 HTML 與 CSS 結構上，進一步加入 JS 讓整個網站從靜態頁面變成具有互動功能的應用。

首先，我們練習了 DOM 操作與事件監聽（Event Handling）。透過 document.querySelector、getElementById 等方式取得元素，並使用 addEventListener 來監聽使用者的點擊、輸入等行為。例如在 home 頁中，我們為按鈕與地圖標記點綁定點擊事件，讓使用者操作可以即時反映在畫面上 。

在地圖功能中，我們使用 JavaScript 動態建立 marker，並隨機分布在地圖上，讓畫面更有變化。當使用者點擊 marker 時，會觸發放大效果並顯示對應的貼文內容（modal），而點擊空白處則會取消選取，這部分透過 class 的切換與條件判斷實現，讓整體互動更加直覺。

在寵物頁面中，我們進一步練習了狀態管理與畫面更新。我們建立了一個 state 物件來紀錄寵物的經驗值、飢餓度與資源，並透過函式動態更新畫面（例如進度條與數值顯示） 。同時也實作了餵食系統，會根據不同食物影響數值，並加入動畫與提示效果，提升使用體驗。

此外，我們也設計了互動式裝扮系統。當使用者點擊衣櫃中的飾品時，會即時更新寵物外觀（例如顯示不同配件），這部分透過 DOM 操作（textContent）來完成，讓畫面能即時反映使用者的選擇 。

在互動細節上，我們加入了更多使用者回饋機制。例如：

點擊寵物時會觸發動畫與對話（隨機或依狀態顯示不同台詞）
使用 setTimeout 控制動畫與提示訊息（toast）的顯示時間
利用 class 切換搭配 CSS transition，讓畫面變化更自然

在 profile 頁中，我們實作了數字動畫效果（count-up animation），讓數據從 0 動態增加到目標值，並加入 tab 切換與按鈕互動（like / reaction），透過狀態切換與數值更新讓介面更有回饋感 。

在 upload 頁中，我們練習了表單互動，包括字數計數器、tag 選取、圖片上傳預覽，以及草稿儲存（localStorage）。使用者輸入時會即時更新字數顯示，並透過 FileReader 顯示圖片預覽，讓整體操作更貼近實際應用情境 。

整體而言，本週的練習重點在於「讓畫面對使用者有回應」，不只是靜態呈現內容，而是透過 JavaScript 讓資料、畫面與操作之間產生連動。

# 2. 額外找了與當週上課的主題相關的程式技術：

除了課堂上介紹的基礎 JavaScript，我們也額外研究了一些與前端互動相關的技術與設計方式。

首先是在「狀態管理」的概念上，我們嘗試用物件（例如 state）集中管理資料，再透過函式統一更新 UI，這樣可以避免畫面與資料不同步的問題，也讓程式結構更清晰 。

另外，我們也實際應用了 localStorage 來實作草稿儲存功能，讓使用者即使重新整理頁面，也可以保留先前輸入的內容，這是前端常見的資料持久化方式 。

在使用者體驗（UX）方面，我們特別關注「操作回饋」。例如：

按鈕點擊後會有動畫或縮放效果
操作成功或失敗會顯示 toast 提示
數值變化會即時反映在畫面上

這些細節雖然不是必要功能，但能讓整體介面更自然、也更接近實際產品。

此外，我們也開始關注前端架構與開發效率，例如 Tailwind CSS 等工具。雖然目前仍以手刻 CSS 為主，但在實作過程中發現許多樣式具有高度重複性，未來若專案規模擴大，導入 utility-first 框架可以有效提升開發速度與一致性。

整體來說，這次除了學習 JavaScript 的語法與功能外，我們也開始思考如何透過程式讓介面更「有回應」，並逐步往互動式應用的方向發展。
